# St.Petersburg-Moscow
Решаем задачу динамического ценообразования билетов на пассажирские поезда маршрута Москва – Санкт-Петербург с использованием методов теории игр. Имеем 5 видов поездов: Купе нефирменный, Купе фирменный, Плацкарт нефирменный, Плацкарт фирменный, Сапсан. Каждый оператор стремится максимизировать свою чистую прибыль. Выигрышом назовем разность между прибылью и расходами (как переменные, так и постоянные). Имеем множество параметров влияющих на ценообразование: общий спрос, количество билетов, уровень комфорта, надежности, частота и скорость. Также имеется возможность добавить нового игрока – ВСМ. Производим сравнение с социальным оптимумом. Ценообразование производится на основе алгоритма best-response dynamics и в конечном счете сходимся к равновесию.
